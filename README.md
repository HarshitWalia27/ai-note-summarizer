# AI Note Summarizer

A simple AI tool that summarizes long text into short, meaningful summaries using NLP (HuggingFace Transformers).

## Features
- Summarizes user input text
- Uses pre-trained transformer models
- Easy to run locally

## Installation

pip install -r requirements.txt

## Usage

python app.py

Enter your text and get summary.

## Tech Stack
- Python
- Transformers
- Torch
